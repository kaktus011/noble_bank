# Noble Bank — Frontend

This is a minimal React frontend scaffold demonstrating:

- React Router for routing
- Custom hooks using React Query + Axios
- Data fetched from `https://jsonplaceholder.typicode.com/`
- UI components with Material UI (MUI)
- Page layout styled with Tailwind CSS


## Quick start (Windows PowerShell)

1. Install dependencies:

```powershell
npm install
```

2. Start the dev server:

```powershell
npm run dev
```

3. Open the URL printed by Vite (usually `http://localhost:5173`).


## Notes

- The demo uses `Posts` page which fetches posts from JSONPlaceholder.
